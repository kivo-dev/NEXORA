# Nexora Dashboard UX

## 1. Purpose

The Nexora Dashboard is the main workspace where users understand their financial activity, trading behavior, portfolio health, and AI-generated insights.

The dashboard changes based on user type:
- Trader
- Crypto Investor
- Wallet User
- Financial Team / Company


---

# 2. First Login Experience

## User Onboarding

After successful login, the user enters an onboarding flow.

The system asks:

### Basic Information

- Name
- Username
- Country
- Experience level
- Main purpose of using Nexora


### User Type Selection

User selects:

1. Trader
2. Investor
3. Crypto Wallet User
4. Financial Team


Based on this selection Nexora generates a personalized dashboard.


---

# 3. Dashboard Layout

## Main Navigation

Top Navigation:

- Dashboard
- News
- Top Traders
- Portfolio
- Settings


Additional sections appear based on user profile.


---

# 4. Dashboard Home

The first dashboard screen shows:

## User Identity

- Nexora username
- Profile
- Account level
- Subscription plan


## Financial Overview

Cards:

- Total Portfolio Value
- Profit & Loss
- Risk Score
- AI Status


Example:

Portfolio Value:
$25,430

Monthly Performance:
+12.4%

Risk:
Medium


---

# 5. Trader Dashboard

For users who select Trader.


## Main Sections


### Trading Journal

Purpose:
Track every trade and create a trading history.


Information:

- Entry price
- Exit price
- Asset
- Position size
- Strategy
- Reason for entering
- Emotional state
- Result


AI analyzes:

- Trading mistakes
- Overtrading
- Risk behavior
- Successful patterns


---

# Portfolio Section

Shows:

- Total assets
- Profit/Loss
- Daily performance
- Weekly performance
- Monthly performance
- Yearly performance


Charts:

- Equity curve
- Performance chart
- Risk chart


---

# AI Report

AI analyzes user behavior.


Examples:

- You increased risk compared to previous weeks.
- You are overtrading.
- Your best performance is during specific market conditions.
- Your win rate improved.


---

# Transactions

Shows:

- Buy/Sell history
- Deposit
- Withdrawal
- Transaction time
- Asset
- Market condition


Optional:

Chart snapshot at trade execution time.


---

# Watchlist

Two modes:


## Manual Watchlist

User creates own list.


## AI Watchlist

Nexora creates recommendations based on:

- Trading journal
- Market condition
- News
- User behavior

# 9. AI Assistant Experience

Nexora AI is available inside dashboard.

User can ask:

- Why did my portfolio decrease?
- What are my biggest risks?
- How was my trading this month?


AI answers using:

- User data
- Transactions
- Market information
- Journal history


---

# 10. UX Goals

The dashboard should:

- Reduce complexity
- Make financial behavior understandable
- Help users improve decisions
- Turn raw data into actionable insights
